Rule definitions

  • InvariantQCWorker: elevated when the unitless primary metric is above 25.
  • SafetyEscalationWorker: critical when the manual flag is set; otherwise elevated when the unitless secondary metric is above 12.
  • ProtocolConformanceWorker: elevated for descriptors containing DISCORDANT, ANOMALY, MUTANT, VIOLATION, FAIL, or REJECT.
  • The highest triggered tier determines the overall demonstration status. No alerts means ROUTINE.

The separate Python API and CLI provide additional audit and batch capabilities, requiring a server and a configured audit key. Those services do not run on GitHub Pages.
